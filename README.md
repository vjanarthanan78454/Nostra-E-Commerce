# Nostra – E-Commerce Website

## 📌 Project Description
Nostra is a basic e-commerce website developed using HTML, CSS, and JavaScript. It provides a simple and user-friendly interface for browsing products and exploring an online shopping experience.

## 🚀 Features
- Responsive website design
- User-friendly interface
- Product listing section
- Interactive elements using JavaScript
- Simple and attractive layout
- Easy navigation

## 🛠️ Technologies Used
- **HTML5** – Website structure
- **CSS3** – Styling and layout
- **JavaScript** – Interactive functionality

## 📂 Project Structure
```text
Nostra/
│
├── index.html
├── style.css
├── script.js
└── images/
```

## ⚙️ How to Run the Project
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore the Nostra E-Commerce Website.
